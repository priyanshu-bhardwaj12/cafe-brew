# The Brew Haven ☕

A professional, modern website for a local artisanal coffee shop and café.

## 🎯 Project Overview

**The Brew Haven** is a fictional yet realistic local coffee shop website designed to demonstrate how a professional online presence can help local businesses:

- **Look more professional** with premium design aesthetics
- **Attract customers** through compelling visuals and content  
- **Increase trust** by providing essential business information
- **Grow online** with a strong digital foundation

## ✨ Features

### Design & Aesthetics
- **Premium Dark Mode Theme** - Warm coffee-inspired color palette
- **Glassmorphism Effects** - Modern, sophisticated UI elements
- **Smooth Animations** - Micro-interactions and scroll animations
- **Custom Typography** - Google Fonts (Inter + Playfair Display)
- **AI-Generated Images** - Professional, cohesive visual assets

### Functionality
- **Fully Responsive** - Mobile-first design, works on all devices
- **Smooth Navigation** - Scroll-based single-page design
- **Interactive Elements** - Hover effects, animations, form validation
- **SEO Optimized** - Proper meta tags, semantic HTML5
- **Mobile Menu** - Touch-friendly hamburger navigation

### Sections
1. **Hero** - Eye-catching landing with call-to-action
2. **About** - Business story and mission
3. **Menu** - Signature drinks and food items with pricing
4. **Gallery** - Showcase of café ambiance
5. **Contact** - Location, hours, contact form
6. **Footer** - Quick links, social media, business hours

## 🛠️ Technologies Used

- **HTML5** - Semantic markup for SEO and accessibility
- **CSS3** - Modern styling with custom properties, animations, glassmorphism
- **Vanilla JavaScript** - Interactive features without dependencies
- **Google Fonts** - Professional typography
- **AI Image Generation** - Custom images created with AI

## 🚀 Getting Started

### Option 1: Open Directly
1. Navigate to the `brew-haven` folder
2. Double-click `index.html` to open in your default browser

### Option 2: Use Live Server (Recommended)
1. Install [VS Code](https://code.visualstudio.com/)
2. Install the "Live Server" extension
3. Right-click `index.html` and select "Open with Live Server"

### Option 3: Python HTTP Server
```bash
cd brew-haven
python -m http.server 8000
```
Then visit `http://localhost:8000`
